## Recommendation

- **Music:** 4 calm children's tracks from Pixabay Music. The Pixabay Content License needs no credit. Each track has a CC0 fallback from Freesound.

## Download and preparation

- **Freesound** needs a free account for the download of the original file. The download link sends a visitor without a session to the login page. The preview files on the CDN are lower quality; do not use them.
- **Pixabay** gives MP3 files. I did not check whether the music download needs a login.
- **Kenney:** the pack page asks for a donation; the download is free. Each pack has `License.txt` (CC0).
- **Trim** long files with ffmpeg, for example: `ffmpeg -i in.wav -ss <start> -t 1.5 -ac 1 -ar 44100 -c:a pcm_s16le out.wav`. Add a short fade (`-af afade=t=out:st=1.3:d=0.2`) to prevent a click.
- **Loudness** (from the `audio-design` skill): keep true peaks at or below -1 dBTP. The files come from many authors, so their levels differ. Measure each file one time, for example with `ffmpeg -i f.wav -af ebur128=peak=true -f null -`, and set each player's volume so that the effects have about the same loudness.

## Format notes for Godot

Source: [Godot docs: Importing audio samples](https://docs.godotengine.org/en/stable/tutorials/assets_pipeline/importing_audio_samples.html), the `godot-audio` and `audio-design` skills, and [godot4-facts.md §4](godot4-facts.md).

- **Formats:** Godot imports WAV, Ogg Vorbis, and MP3. The docs advise WAV for short effects that repeat, and Ogg Vorbis for music. MP3 also works, so the Pixabay MP3 files and the fanfare MP3 need no conversion. The docs list no FLAC import, so convert the FLAC fallback (By the Sea) to WAV or OGG.
- **Effects as WAV:** convert each effect and each Sea friend sound to WAV, 16-bit, 44.1 kHz, mono. Import options: Edit > Trim on (it cuts silence below -50 dB at each end, with a 500-sample fade), Loop Mode "Disabled". Compress > Mode "Quite OK Audio" (the default) is good.
- **Music loop (Ogg Vorbis and MP3):** set the import option Loop on. Loop Offset (in seconds) sets where the second pass starts. Ogg and MP3 have no "loop end": the loop always starts again at the end of the file. The Pixabay tracks are probably songs with an intro and an end, not seamless loops [INFERENCE]. Thus:
  - Cut the fade-out at the end of the track with ffmpeg (`-t <seconds>`), then set Loop Offset to the end of the intro. Use the Advanced Import dialog to listen to the loop point before the import.
  - Or turn Loop off and crossfade to the start of the same track when it ends (pattern 3 "Crossfade" in the `godot-audio` skill). The same crossfade changes the music when the Area changes.
- **WAV loop points**, if a music file is WAV: Loop Mode "Forward", with Loop Begin and Loop End in samples from the file start (Loop End -1 means the file end).
- **Signal:** a player with a loop does not emit `finished`.
- **Buses:** route music to a `Music` bus and all effects and Sea friend sounds to an `Effects` bus. The volume buttons change these two buses (`AudioServer.set_bus_volume_linear`, the square of the button value). Use 0 as mute.
- **Move swish:** the Child moves often. Put the swish in an `AudioStreamRandomizer` with `random_pitch_semitones = 1.0`, so the sound does not repeat exactly. Set `max_polyphony` to about 4.

## What I checked

- Each Freesound link above returns HTTP 200 (curl, 2026-11-03). Each page links to the licence in the table. The otter page links to CC BY 4.0; all other picks link to CC0 1.0.
- Each Freesound title, length, and file type comes from the sound page. Each short description in the tables comes from the author's text or tags on the page.
- The 6 Pixabay music pages in this file return HTTP 200 in a headless Chromium. Pixabay sends HTTP 403 to curl (a Cloudflare check). The license summary page also returns HTTP 200 in Chromium; I read its text.
- The Kenney category page and the Music Jingles page return HTTP 200. I downloaded 7 Kenney packs to `/tmp`, read the file lists and `License.txt`, and measured the jingle lengths with ffprobe. I did not add audio files to the repo.
- The Godot docs page returns HTTP 200. The Godot import facts come from its text.

The Parent or an agent must listen to each file before the build, and replace a file that is too loud, too sharp, or scary for a 5-year-old. Each music track and each effect has a fallback. A Sea friend with a bad file can use the splash.
- I did not find the trim start times for the 6 long files (Spouting whale, Whale, Blowfish, Otter, Swan, Flamingo).
- I did not check whether the Pixabay tracks loop without an audible jump.
- I did not download any Freesound or Pixabay file.

## Effects on other tickets
