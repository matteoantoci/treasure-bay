# Pick the theme: sea or space

Type: prototype
Status: resolved
Blocked by: 07
Map: [Labyrinth game for a 5-year-old](../map.md)

## Question

Which theme is better for the Child? The Parent decides. The Child does not test the mockups.

- Sea: for example, a boat that finds an island.
- Space: for example, a rocket that finds a planet.

Make two rough static mockups. Each mockup shows the character, the Goal, the walls, and the reward screen. Show both mockups to the Parent. Record the choice and the reason.

## Context

From [Source the graphics](07-source-the-graphics.md): use the Fluent Emoji 3D PNG files for the mockups. The style candidates for each theme are in [research/graphics.md](../research/graphics.md). Godot uses the PNG files, not the SVG files, because its SVG support is limited.

## Answer

Theme: **sea**. A sailboat finds an island. The items are shells and fish.
The Parent chose sea over space. The base look is the "Sea (light)" variant: blue walls on a light floor. The "Sea (sand paths)" variant can be a second look.
New request from the Parent: as in real games, a change of Labyrinth must also change something in the graphics. See [Visual change between Labyrinths](08-visual-change-between-labyrinths.md).
Prototype (throwaway): [prototypes/theme-PROTOTYPE/index.html](../prototypes/theme-PROTOTYPE/index.html). To view it, run `python3 -m http.server` in that directory.
