Build note (gf/05-name-and-opening-screen): `project.godot` has the name "Treasure Bay", which is also the window title. `tools/make_app.sh` builds `~/Applications/Treasure Bay.app` with the executable, the icon and the log `~/Library/Logs/Treasure Bay.log` under the same name. It does not delete an old `Labyrinth.app`: the Parent deletes it by hand. User folder: no custom user folder (Parent decision, 2026-11-22). user:// follows the new name, `~/Library/Application Support/Godot/app_userdata/Treasure Bay/`, so the first launch after the rename starts with fresh progress. The old save stays untouched in `app_userdata/Labyrinth/`. Font: Fredoka from the Google Fonts repo (`ofl/fredoka/Fredoka[wdth,wght].ttf`, a variable font, renamed to `assets/fonts/fredoka/Fredoka-Variable.ttf`) with `OFL.txt` next to it and a new section in `credits.txt`. `src/game_font.gd` (`GameFont.bold()`, one shared `FontVariation` at weight 600) is the place for tickets 07 and 08. Opening screen: `src/opening_screen.gd` (node `Opening` in `main.tscn`, after the Item row and under the gear) and `src/start_button.gd`. The values are in the build spec section 10. The Collection strip draws above the reveal layer of ticket 11, so it is also above the opening screen: the main scene hides the strip while the opening screen shows. The island is `IslandLook.block(Vector2i(4, 3), 1)`, a new builder that uses the cell rules of the Labyrinth islands, so ticket 07 can use it for the Party. The title draws each letter with `draw_char` on an arc of radius 600 px: the prototype radius (420 px of 1000, so 504 px at 1200) made the end letters touch the island. The acceptance test now allows `draw_char` in `opening_screen.gd` only, and the only text on the opening screen is the name. The new action is `confirm` (Space and Enter, physical keys). The main scene reads it only while the opening screen shows. In play, Space and Enter still do nothing. Ticket 07 uses `confirm` for the Party. Start press: the button scales to 0.86 and back in 140 ms, `item.wav` plays, the screen fades to dark in 0.8 s (`inout`), then `start_with_fade()` shows the Labyrinth and fades in from dark in 500 ms. Difference from the old launch: the opening screen shows at once at launch, with no fade-in from dark. A Parent reset shows the opening screen with the new Voyage. The opening screen plays the music of Area 1, and the start press crossfades to the music of the Area of the current Labyrinth. Tests: `Scene.add_main()` now goes through the opening screen with the new helper `start_from_opening()` (Space). `add_main_at_opening()` stops on the opening screen. The tests of the launch fade-in and of the reset now go through the opening screen.
